# Echo ECU — Code Agent Instructions

## Scope

This file governs `echo_ecu/` only — a single-file (`echo_ecu.py`), stdlib-only
DoIP ECU stub that always responds with a canned echo. See `../CLAUDE.md` for
why this differs from `test_ecu/`.

## This component is frozen — treat any change as high-risk

`echo_ecu.py`'s DoIP framing (constants, `_build`/`_ptype`/`_payload`,
`_fmt_hex`) is asserted **byte-identical** to `test_ecu/testecu/doip.py` by
`test_ecu/tests/test_doip_parity.py`, which imports this file directly by
path. If you change constants, frame layout, or the announcement payload
here, that test will fail — that is intentional, not a false positive to
silence. Do not edit this file to fix a TestEcu bug; fix it in
`test_ecu/testecu/doip.py` and expect the two to diverge (which is fine —
`echo_ecu` is not required to track TestEcu).

Only touch this file for:
- an actual bug in the echo/ACK/announcement behaviour that affects EdgeNode
  or TestEcu development, confirmed against `../doip_edgenode_requirements.md`;
- explicitly requested changes.

Do not "clean up", refactor, add type hints beyond what's there, split into
modules, or add a license header as a drive-by change — this file is
deliberately a single, frozen, working reference implementation.

## Conventions (if you must touch it)

- Pure Python stdlib only — no PyYAML-adjacent dependency additions beyond
  `pyyaml` for config, no Scapy, no third-party UDS libs.
- No license header (unlike `test_ecu/`).
- DoIP constants are prefixed `_` (module-private) except the `PT_*`
  payload-type constants and `PTYPE_NAMES`, which parity tests import.
- Runs as its own single-directory Docker build context
  (`docker/echonode.Dockerfile`) — do not add imports of files outside this
  directory.

## Behaviour reference

See the module docstring at the top of `echo_ecu.py` for the full behaviour
list (Routing Activation → `0x10`, Diagnostic Message → ACK + echo with a
random 4-byte trailer, Alive Check, Entity Status, Power Mode, UDP
announcement/identification). `../README.md` §"Echo ECU or TestEcu?" explains
when to use this vs `test_ecu/`.
